# Asset register

Every file under `assets/` has one row here; `pnpm lint` checks it
(`scripts/check-assets.mjs`). Licenses were checked on the source's own
license page on the date shown. Allowed: CC0, CC BY, MIT, ISC, Apache 2.0,
zlib, SIL OFL. NC and ND licenses are rejected unless the designer approves.

Icons are stored single-colour (`fill="currentColor"`, background square
removed); that is a permitted adaptation under CC BY 3.0.

Status: `in use` (file is in `assets/`), `candidate` (license verified,
not downloaded yet; the named phase downloads it), `rejected`.
