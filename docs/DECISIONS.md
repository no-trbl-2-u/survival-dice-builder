### 23. Order of card bottom halves and their reroll effects (rule 7.8 step 5)

- Status: proposed (phase 5)
- Reading: The player plays cards one at a time in any order; a numbered reroll ("Reroll 2 dice") rerolls that many **different** dice, picked one at a time; the player may stop early. "Reroll all" rerolls every die, kept or not. Card rerolls do **not** count toward the 3-roll maximum (7.8 step 4). A Combat draw with fewer than 3 cards left draws them all, as 6.5.
- Setting: engine code

### 24. How many defenses may stand on one hex? (rule 12.2)

- Setting: engine code `canBuildOn`

### 25. Who chooses where the setup countryside tile goes? (rule 4.2 [006])

### 26. What does it cost to enter a hex that holds an enemy? (rule 6.9, 6.15)

- Setting: engine code `spawnHex`

### 33. May an enemy enter a Tower hex? (rule 9.3, 9.4, 12)

- Status: proposed (phase 7)

### 34. "Nearest" for a target: straight distance or walking distance? In what order do enemies move? (rule 9.3)

- Status: proposed (phase 7)
- Reading: **Straight hex distance** ranks targets; the enemy then walks the shortest open path (9.7 when blocked). Enemies move **oldest first**; Towers attack oldest first.
- Setting: engine code `rankTargets`, `moveEnemies`

### 35. Which enemy does a Tower hit when 2 are equally near? (rule 12.3)

- Status: proposed (phase 7)

- Setting: engine code `towerAttacks`

- Setting: engine code `vacantNodes`, `refillNodes`

### 37. Automatic exploration: where does the tile go? (rule 18.1)
