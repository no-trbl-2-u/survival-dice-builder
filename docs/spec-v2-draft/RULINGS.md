## What the rulings change in the game (engine and content work)

Spec v2 will say these; the engine does not do them yet. Each one is
a rule change, so it ships with tests and a `RULES-COVERAGE.md` row.

1. Drop the 8-card / hand-of-3 preset (ruling 7).
2. Remove the skirmish: a figure cannot enter an enemy's hex; Engage
   is the only way into combat; Engage may sit on a Prepare half
   (ruling 12). Blink can no longer enter an enemy's hex.
3. Gather amounts: Haul 3, Forage 2, Excavate 4, Quarry 6 (ruling 13).
4. Enemy dice and siege damage read from each enemy's record, not a
   grunt/elite rule (rulings 15, 17).
5. Drop the exchange-only enemy options (rows 69, 74) and the fixed
   v1 enemy damage (ruling 18).
6. Experience steps of 3 by default; the step stays a knob (ruling 20).
7. Build and Repair split; levelled Build (ruling 25). Needs card
   content: Repair, Build II, Build III.
8. Draft offers 2 new Skills per player plus that player's pool
   (ruling 26); an empty supply falls back to the next lower level
   (ruling 28).
9. A knockout loses currency as well as materials (ruling 30).
10. Drop the once-per-engagement Skill option (ruling 31).
