# Playtest survey

About 5 minutes per player, right after the run. Ratings are 1 (strongly disagree) to 5
(strongly agree). Each "one line" answer is optional but is the best evidence for a change.

| # | Question | Answer |
| --- | --- | --- |
| 1 | The trip out to gather and back to the base felt **tense** (not tedious). | 1-5 + one line |
| 2 | The 6-card deck was the right size (not too short, not too long). | 1-5 + one line |
| 3 | The wave track felt fair: I saw the danger coming. | 1-5 + one line |
| 4 | Which Skill felt best? Which felt useless? | one line each |
| 5 | Rolling and keeping dice was fun, not fiddly. | 1-5 |
| 6 | I always knew what I could do next. | 1-5 + the moment you did not |
| 7 | Which rule confused you, and when? | one line |
| 8 | The run was the right length. | 1-5 |
| 9 | Co-op only: turns moved at a good pace, and I had real choices on other players' turns. | 1-5 + one line |
| 10 | I would play again tomorrow. | 1-5 |
| 11 | The one thing you would change. | one line |
