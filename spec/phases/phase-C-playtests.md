# Phase C — Playtest protocol and first playtests (non-code)

**Goal:** turn real play into decisions for Spec v2.

## Scope

1. **Protocol:** a one-page script: setup, rules teach (time it), play, short survey.
2. **Sessions:** at least 5 solo runs by the designer and 3 co-op sessions with others.
3. **Data:** collect each run export (timings, rounds, cause of end) and survey answers.
4. **Survey questions (examples):** Did the out-and-back trip to the base feel tense or tedious? Was the 6-card deck too short? Did the wave track feel fair? Which Skill felt best?
5. **Report:** median run length in rounds and minutes, top 5 friction points, proposed rule changes for Spec v2, and whether to start scenarios (rules section 19).

## Acceptance criteria

- The report compares real minutes per round with the simulator estimate (about 8 to 9 minutes per round at a normal table).
- Each proposed change names the rule id and the evidence (data or quote).
