# Phase B — Art direction and placeholder art (non-code)

**Goal:** a consistent, readable look for the prototype using Phase A assets, with no original art required.

## Scope

1. Pick a palette and type pairing for a theme-neutral setting (the theme is still open).
2. Define readability rules: enemy health pips, structure health bars, legal-move highlights, phase colours (Prepare, Combat, Explore).
3. Card template: top half and upside-down bottom half, coloured edge bands for orientation, level marker (I, II, III), cost.
4. Die face sheet: 6 faces on a d6 net, for both 2D SVG dice and 3D dice textures.
5. Tile template: 7-hex tile with printed sites (base, gathering node, spawn node, elite spawn node).
6. Mock-ups of the main screen and the run summary for Phase 5.

## Deliverables

- `ART-GUIDE.md` with palette tokens, type scale, icon sizes, and do/don't examples.
- SVG templates: card, die net, tile, base board.
- Two screen mock-ups (PNG or SVG).

## Acceptance criteria

- Text and icons pass WCAG AA contrast in light and dark themes.
- A first-time viewer can identify card orientation, enemy type, and health at a glance (check with 2 people).
- Every template uses only assets listed in `ASSETS.md`.
